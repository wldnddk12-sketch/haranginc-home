- 호스팅: Cloudflare Workers(정적 파일). GitHub main 브랜치에 올리면 1~2분 뒤 자동 배포.
- 빌드 과정 없음. 메뉴마다 별도 페이지(html 7개). **각 html 파일 안에 스타일·이미지가 모두 들어 있어 다른 파일이 필요 없음.**
