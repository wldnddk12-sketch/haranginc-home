# 하랑아이앤씨 회사 홈페이지 (haranginc.co.kr)

- 호스팅: Cloudflare Workers(정적 파일). GitHub main 브랜치에 올리면 1~2분 뒤 자동 배포.
- 빌드 과정 없음. **모든 파일은 폴더 없이 저장소 맨 위(루트)에 둔다.** (폴더 업로드가 누락되기 쉬워서)
- 원본 생성 스크립트는 Claude 작업 공간에 있음. 수정은 각 HTML을 직접 고쳐도 됨.
